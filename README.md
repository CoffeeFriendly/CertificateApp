# Certificates App

REST API для создания и управления заявками на получение справок. Реализует следующую бизнес-логику: защиту от дубликатов, машину состояний статусов, ролевое разграничение доступа (Сотрудник / Бухгалтер) без реализации авторизации и базовую историю изменений статусов в заявках.

# Стек
Платформа - ASP.NET Core Web API (.NET 8/10)
БД - EF Core + SQLite

## Быстрый старт

### Требования
- .NET 8+ SDK
- Git

### Запуск
```bash
# 1. Клонируйте репозиторий
git clone "https://github.com/CoffeeFriendly/CertificateApp"
cd CertificatesApp

# 2. Запустите проект
dotnet run

# 3. Откройте Swagger UI
http://localhost:5249/swagger
```

### При первом запуске автоматически создаётся файл certificates.db и заполняется тестовыми пользователями (Seed Data). Никаких дополнительных настроек БД не требуется.

| Роль | ID (GUID) | Возможности |
|---|---|---|
| **Сотрудник** | `11111111-1111-1111-1111-111111111111` | Создание заявок, просмотр своих, отмена своих |
| **Бухгалтер** | `22222222-2222-2222-2222-222222222222` | Просмотр всех заявок, управление статусами |
| **Сотрудник 2** | `33333333-3333-3333-3333-333333333333` | Аналогично первому сотруднику |

Примеры запросов можно увидеть в интерфейсе Swagger

В связи отсутствием реализации авторизации, оценка наличия прав на те или иные операции с заявками происходят исходя из переданного id сотрудника. При GET запросе, подразумевается что сотруднику был бы доступен только GetByEmployee на свой id.
